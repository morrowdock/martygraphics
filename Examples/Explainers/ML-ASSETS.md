# ML sample artwork

[ml-dog.png](ml-dog.png) is an original dog illustration made for these examples from procedural shapes and colors. It uses no external stock or source photo. The original asset is released under CC0 1.0 Universal. The source is this repository's PNG.

The 32 × 32 source uses opaque 8-bit RGB pixels. The picture, meaning-map thumbnail and attention sample store byte-identical Base64 copies of this PNG. The kit decodes those bytes at validation time.

The image, map positions, logits and attention scores are illustrative. The examples describe how image-reading AI models can work in general. They make no claim about ChatGPT's architecture.
