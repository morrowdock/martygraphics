# Security policy

This is an early preview. Only the latest main branch is considered for security fixes;
there is no security support SLA or supported stable release yet.

Report vulnerabilities privately to **admin@morrowdock.app**. Include affected commit,
impact, and minimal synthetic reproduction steps. Do not post vulnerabilities, secrets,
personal data, or private course material in public issues. Coordinate disclosure after
a fix is available. Never include credentials in a report.
