# MartyGraphics v0.2 plan: recorded gaps

Status: **proposed** (2026-11-11). G2 (the transcript export) is built and merged ([#68](https://github.com/morrowdock/martygraphics/pull/68)); every other item waits for the owner's go.

Owner decision (Collin Craig, 2026-11-11): the engine feature freeze is partly lifted on a side track, to bring the
engine up to date with how it is used now (course explainers, Blender export, iPad). This plan is the **gap track**:
it grows the vocabulary only where a real authoring run recorded a gap. Every item names the gap file and item it
closes. The visual-quality track (lighting, materials, background, label plate styling) has its own owner and plan;
it is not in this file.

Rules that stay:

- `benchmark/` (its LOCK and HASHES) and the mechanisms-v1 engine pin (`38f3863`, in marty's `Package.swift`) do not
  change. No item below touches them.
- No change to an existing reason code, to the bytes of an existing report, or to `--strict` for an existing document.
  New keys are optional; a document without them gives the same bytes as before. Where a golden must change, the PR
  says which and why.
- One small PR for each item, with golden or unit tests and doc updates (SOLID-3D.md or EXPLAINER.md, CHANGELOG,
  FILES.json).
